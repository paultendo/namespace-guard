# Privacy

namespace-guard and its skill collect nothing.

- **The npm package** runs in your own project and makes no network calls. It doesn't collect, store or send any data.
- **The skill** for Claude Code, Codex and other agents is instructions only. It tells the agent how to use the package, contains no code, and sends nothing anywhere.
- When the skill helps check names you already have, such as a users export with `audit-canonical`, that happens on your machine and nothing is kept.

Questions: open an issue at [github.com/paultendo/namespace-guard/issues](https://github.com/paultendo/namespace-guard/issues).
